# Level 3 — AI Challenge

Level 3 is intended for learners who already have substantial experience with Python and AI/deep learning and would prefer to spend the hands-on session working independently on a competitive challenge.

The actual challenge, code, and data will be provided **on site**. This repository deliberately does not contain the challenge details in advance.

## What to expect

You will receive a working baseline project and the data needed for development.

Your task will be to understand the supplied pipeline, decide what is worth changing, test your ideas, and improve the final result.

The challenge is intentionally open enough that there is no single correct solution. You should expect to make decisions about an existing AI pipeline rather than build everything from scratch.

## What you should be comfortable with

Level 3 assumes that you already have practical experience with most of the following:

- Python
- PyTorch or a similar deep-learning framework
- training and evaluating neural networks
- working with medical-imaging data
- debugging an existing codebase
- interpreting training and validation results

Experience with MONAI is useful, but not required.

If several of these topics are new to you, **Level 2 is probably the better starting point**. You can still move between levels during the school.

## Computing environment

The challenge is designed to run on a **standard free Google Colab runtime**.

Before the course, please make sure that you can:

1. open and run a Google Colab notebook;
2. change the runtime type;
3. enable a GPU runtime when one is available;
4. upload files to the Colab session;
5. navigate and edit files in the Colab file browser.

You do not need to download any challenge data in advance.

## On site

The complete challenge package will be supplied locally.

Please bring a laptop that can access Google Colab and can read a USB storage device.

The challenge instructions, rules, evaluation procedure, and submission format will be explained in the notebook supplied on site.

## LLMs

Modern AI development very commonly involves LLMs and coding assistants. Their role in the challenge will be explained together with the full challenge rules on site.

The important principle throughout this course remains the same:

> Running code is not the same as understanding whether the code is correct.

## Time

The Level 3 challenge runs during the hands-on tutorial block. You may also move between levels if you decide that another level is a better fit.

There is no benefit in preparing anything specific before the course. Familiarity with the tools and environment is enough.
