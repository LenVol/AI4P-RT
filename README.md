# AI4P-RT
A collection of python notebooks for teaching AI, with a particular focus on MONAI, to students in the radiotherapy domain.

These notebooks were creeated for the 2nd UPLIFT School on "AI in Radiotherapy" and the AI4P|RT workshop help on November 1-7, 2026, in Monte Verita, Switzerland. 

The school [website](https://indico.psi.ch/event/18878/registrations/2885/) provides further infos on the lectures. 

## Other tutorials

This course work heavily builds on existing tutorials, and partly copies or reuses the same material. For indepth documentation, refer to the official websites linked below.  

* [MONAI tutorials](https://github.com/Project-MONAI/tutorials/)  
* [carpentries.io tutorials](https://carpentries-lab.github.io/deep-learning-intro/)

The tutorial gears toward [MONAI](https://project-monai.github.io/) because it is extremely taylored to medical applications, and very useful for radiotherapy. In very many radiotherapy applications, MONAI already provides the buidling blocks needed. In addition, MONAI is PyTorch at its core, so the training applies to torch as well. 

However, if you are looking for an indepth AI training, I can recommend the carpentries tutorials. They are really instructive and kept up to date. 

A deep learning book I recommend is "Deep Learning" by Ian Goodfellow, Yoshua Bengio and Aaron Courville. It covers all basics and is very informative. 

## What this tutorial does not cover

Most modern AI applications go far beyond this relatively simple-kept tutorial. We deliberately do not cover transfromer architectures, ensembles, or uncertainty estimation. 

In the future we might expand this tutorial and keep it open for learners, but for now, there are plenty of options that are fit for the task, so that it seems unnecessary to add more.

## How to use this tutorial 

The tutorial is separated into three distinct levels. 

1. Level 1: intended for non-coders or learners with very limited coding experience. Covers LLM coding.
2. Level 2: intended for learners with python experience, interested in getting started with AI. Covers basic AI principles and good practices. 
3. Level 3: intended for people with extensive AI background. Level 3 is a competitive challenge (with a price offered on site during the UPLIFT School)

Prior to the hands-on tutorial, we ask you to choose one of these levels for yourself. 

Each level is intended to cover roughly 3 hours. In the second 3h block, you will be shown an overview over commercial software and 3DSlicer.
